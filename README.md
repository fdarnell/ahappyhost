# A Happy Host — ahappyhost.com

Static website for **A Happy Host, LLC**, a short-term rental concierge company in
Pigeon Forge, TN. Rebuilt as plain HTML/CSS/JS (no framework, no build step
required to serve) for speed, SEO, and easy hosting on Vercel.

## How the site is put together

| Path | What it is |
|---|---|
| `*.html` | The 11 pages plus `404.html` — **generated files**, don't hand-edit chrome |
| `scripts/build.py` | The generator. All page content, header, nav, and footer live here |
| `site.config.json` | Business facts (phone, address, hours, emails, social links) |
| `css/style.css` | The one shared stylesheet. Brand colors are CSS variables at the top |
| `js/main.js` | Mobile nav, carousels, contact form (~80 lines, no dependencies) |
| `images/`, `fonts/`, `downloads/` | Self-hosted assets (no external CDNs) |
| `sitemap.xml`, `robots.txt`, `llms.txt` | SEO/AEO files — `sitemap.xml` is regenerated by the build |

### Editing content

1. Edit the page body or business fact in `scripts/build.py` (and
   `site.config.json` if it's a business fact).
2. Run `python3 scripts/build.py` from the repo root — it rewrites every HTML
   page with identical header/nav/footer and regenerates `sitemap.xml`.
3. Commit both the script and the regenerated HTML.

Small one-off text fixes directly in an HTML file work too, but keep
`build.py` in sync or your fix will be overwritten on the next build.

After any edit, sanity-check that the phone number and address are identical
everywhere: `grep -c "865-314-7564" *.html`

## Preview before publishing

- **Local preview:** from the repo root run `npx serve .` (or
  `python3 -m http.server 8000`) and open the printed localhost URL.
- **Staging:** production deploys from `main` only. Put edits on a branch and
  push it — Vercel gives the branch a private preview URL you can review and
  share. Merge to `main` to publish.

The loop: *edit → build → local preview → push branch → check preview URL → merge.*

## Deploying to Vercel

1. Push this repo to GitHub.
2. At [vercel.com/new](https://vercel.com/new) import the repo.
   Framework Preset: **Other**. No build command, no output directory —
   deploy as-is.
3. Add the `ahappyhost.com` and `www.ahappyhost.com` domains in the Vercel
   project settings and update DNS at the registrar.

`vercel.json` already handles clean URLs (`/about` → `about.html`), long-term
caching for assets, and security headers. `404.html` is served automatically.

## SEO notes

- Every page has a unique title, meta description, canonical URL, Open Graph
  tags, `LocalBusiness` JSON-LD, and breadcrumb structured data on subpages.
- Service pages additionally carry `Service` JSON-LD scoped to
  Sevierville / Pigeon Forge / Gatlinburg.
- `robots.txt` explicitly allows AI crawlers (GPTBot, ClaudeBot,
  PerplexityBot, Google-Extended); `llms.txt` gives them a clean summary.
- All fonts and images are self-hosted; there are no third-party requests.
